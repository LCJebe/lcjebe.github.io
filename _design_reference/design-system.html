Pairings explored
A · Selected default
Fraunces / Inter Tight
Fraunces gives display warmth without becoming literary; the variable SOFT axis lets us soften corners at large sizes for the name and harden them at smaller sizes for headings. Inter Tight is the modern engineering-portfolio default — neutral but slightly tighter than Inter, which reads as intentional. This is what the rest of the system is built on.
B · Alternate
Fraunces italic / Inter Tight
Same families, italic display variant. More editorial, more "writer," slightly less "engineer." Worth keeping as a fallback if the brief tilts more toward the Craig Mod / writer-photographer end of the reference set. Same body type so the rest of the system is unchanged.

05

Anti-patterns

Things this system specifically refuses to do.

No three-section axis split. Creative, personal, and accomplished must combine within single elements. The hero is the canonical example: portrait + voice + venues, not stacked.
No card-shadow-radius treatment. Hairline dividers do the separating. Cards only when content genuinely groups (one used, sparingly, on the design-system page itself).
No invented imagery. Every photograph in this system is one of his own. If we ever need a placeholder, it's a striped block, not a generated image.
No off-scale spacing. If a layout wants 20px, the answer is 16 or 24, not 20.
One craft moment, not many. Subtle hero-photo crossfade. No scroll-jacking, no entrance animations, no parallax.
